Demo formulario

Este input no permitirá la inserción de números y limitará la longitud a 10 caracteres. Además, la primera letra de cada palabra se pondrá en mayúscula automáticamente.

Valor interno: . (Numero de opciones: )
El valor interno solo cambiará al seleccionar una opción, no al randomizar las opciones. Esto demuestra que el select es controlado y no se resetea al cambiar las opciones. En el caso de que la opción seleccionada desaparezca, el select se quedará sin selección, pero el valor interno se mantiene hasta que el usuario seleccione una nueva opción.
